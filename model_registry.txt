# ============================================
# 模型清单（随仓库维护，进 git；AI 可改区）
# 全项目所有模型名集中在本文件，与 .env（端点 / KEY / LLM 参数等配置）分开：
#   .env              只写 端点、KEY、LLM 参数、协作参数（.gitignore 排除，永不提交）
#   model_registry.txt 只写 模型名清单（本文件），git pull 即更新，AI/脚本可安全改写
#   明确分工：模型名不许写进 .env（那样会盖住本文件的 git 更新和自动下线，
#   启动时会打 [配置分层提醒] 警告）；配置值也不许写进本文件。
# 本文件变量与 config.yaml 里的 ${...} 一一对应，填别的名字不生效。
# 格式同 .env：KEY=VALUE，注释必须独占一行（不支持行内注释）。
# @数值 = 该模型上下文窗口（k 表示 ×1024）：256k=262144、512k=524288、1024k=1048576(1M)。
# 临时屏蔽某模型 = 在模型名前加 #（如 #laguna-s-2.1@256k），注释即下线不用删。
# 新增模型 = 按 "模型名@窗口" 逗号追加。
# 自动下线机制：某模型连续 7 个"运行日"（程序实际启动过的天，周末没开机不计入也不
# 打断）每天请求都失败，会自动在本文件对应行的模型名前加 # 屏蔽（删掉 # 即恢复；
# LLM_MODEL 兜底行不自动动，人工决定）。
# ============================================
