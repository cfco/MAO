### 五、验证证据

**修复后实测**

- 健康档案：两个 `WorkerPool` / 两个 `Agent` 共享同一实例 → `True`；交错记账后档案 `models = ['node-a','node-b']`（原为只剩 `node-b`）。
- 派工规模：`ask_many` 5 次、`vote` 10 次、`pipeline` **20 次**（原 100 次）；限时自适应 1 名→150s、5 名→270s、25 名→1110s，显式传入 0.3s 优先。
- 缓存契约：冷却中且已缓存 → `collect` 返回 `[(worker, '缓存里的答案')]`、`ask_many` 含缓存答案；无缓存时仍如实输出"错误：工人冷却中，本轮跳过"。
- Web lifespan：二次进入存活清理线程 **1** 个（原 0），退出后无残留。
- MCP 共享：两次 `acquire_group` 同一实例、`refs=2`、连接数恒为 1；释放一次仍在共享表，归零后移除。
- 上下文预算：长 system 保留历史 8 条 < 短 system 11 条（扣减生效）。
- 计票：错误文本不再产出选票（`select_best` 返回 `None`），正常投票仍正确解析。
